# Student Grade Tracker

## About
A Java application for managing student records and tracking student marks.

## Features
- Find student records
- Add student marks
- Track grades
- Handle invalid mark inputs

## Technologies
- Java
- IntelliJ IDEA
- Git and GitHub

## Project Files
- `Main.java` — Starts the application
- `Student.java` — Stores student information and marks
- `GradeTracker.java` — Manages student records and grades

## How to Run
1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Configure a compatible JDK.
4. Run the `Main` class.
